# Shanshan Luo — Academic Website

This repository contains the source files for the public academic website:

- English homepage: https://shanshanluo.cn/
- Chinese homepage: https://shanshanluo.cn/cn/

## Repository contents

The repository intentionally keeps only files needed by the public website, including page source, stylesheets, the custom-domain configuration, profile images, and documents linked from the live pages.

Historical drafts, obsolete page versions, and internal maintenance materials are kept in the private repository [shan3luo1995-copy](https://github.com/shan3luo1995/shan3luo1995-copy).

Please do not remove or rename assets referenced by `index.html` or `cn/index.html` without updating the corresponding page links.
